Actual vs Target Financial Performance Dashboard 
An interactive Power BI dashboard designed to analyze actual financial performance 
against target values. 
Key Features 
•     Actual vs Target analysis 
•    Total Actual & Target Value 
•       Variance and Variance % 
•    Salesperson & Team-wise analysis 
•              Date-based performance tracking 
•        Interactive slicers and KPI cards 
Tools Used 
Power BI | Power Query | DAX | Excel 
Project Structure 
• Dataset/ – Source Excel dataset 
• PowerBI/ – Power BI dashboard 
• Documentation/ – Project & Solution Design Documents 
• Screenshots/ – Dashboard preview 
Objective 
To provide a clear and interactive view of financial performance, helping users identify 
target achievement, gaps, and performance trends.
